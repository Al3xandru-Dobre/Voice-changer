## Defects found & fixed

| Tag | Defect | Fix |
|---|---|---|
| [BUG-010](BUG-010_liveness_ignores_callback_progress.md) | `is_stream_live()` ignored the callback-progress counter — spec requires liveness from **4** signals (controller state + notifications + backend state + callback progress); a dead RT thread on a still-"started" device would be reported live forever | `callback_stall_timeout` (2 s default): `tick()` treats a frozen `frames_processed()` as an interruption → bounded `Recovering`; baseline re-armed on each open |
| [BUG-011](BUG-011_preopen_retryable_failure_bypasses_recovery.md) | Retryable pre-open catalog failures (`DeviceBusy`/`EnumerationFailed`/`BackendUnavailable`) went straight to terminal `Error`, bypassing the bounded-retry policy that identical errors take one call later; and `Recovering` could never heal a generation-0 catalog | One classification point (`enter_failure_state`); `Recovering` rebuilds the catalog inside the retry attempt when `generation == 0`; feedback-refusal paths now use the shared `fail()` (clears stale `resolved_*` keys) |
| [BUG-012](BUG-012_unavailable_refresh_left_snapshot_fresh.md) | `refresh()` `Unavailable` exit didn't mark the retained snapshot `stale` (the other two failure exits did) | `stale_ = true` on that path too |

New regression tests in `test_audio_controller.cpp`:
`test_stalled_callback_is_not_live_and_recovers`,
`test_retryable_catalog_failure_enters_bounded_recovery`.

## Stage 05 checklist verified

- [x] Single control thread owns enumeration/probe/open/close/retry (`AudioController`)
- [x] `notificationCallback` only `fetch_or`s lock-free atomic bits — no SPSC queue, no lifecycle work (`MiniaudioBackend::on_notification`)
- [x] `dataCallback` → `DuplexRouter::process` only: SPSC + atomics + memcpy/memset — no alloc/lock/log/I/O
- [x] 1 s periodic refresh + on-demand + hint-triggered; bursts coalesced via bitset drain; bounded exponential backoff on refresh failure (`min(max, init << min(failures-1, 5))`)
- [x] Liveness = state + notifications + backend state + **moving callback progress** (after BUG-010 fix); silence still counts as progress
- [x] Switch transition order enforced & tested: quiesce worker → stop stream → discard both queues → `InferencePipeline::reset()` → reopen; `last_discarded_samples` proves no PCM leak
- [x] Explicit capture/playback vanish → `AwaitingUser` + `DeviceNotFound`, never substitutes (fake tests + policy)
- [x] Follow-default: `auto_routes_default()` (WASAPI/CoreAudio) updates resolved keys in place without duplicate restart; other backends serialized reopen; reroute into feedback route refused
- [x] `PermissionDenied` → `AwaitingUser`, zero retries; busy/server errors → bounded `Recovering` → `Error` on exhaustion
- [x] Epoch invalidation: dead-epoch keys → `DeviceChanged`; follow-default re-resolves on new epoch
- [x] Client vs. backend rates/periods reported separately (`StreamInfo`, printed at startup)
- [x] Bounded output queue (`write_output_bounded`, default 5120 samples) with drops counted — conservation identity `queued = underruns − overruns − drops` preserved
- [x] Capture-only/loopback null-buffer contract (`out == nullptr` → capture-only path; tested in `duplex_router`)
