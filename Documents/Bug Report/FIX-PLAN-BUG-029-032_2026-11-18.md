## Critique of the plans (pre-implementation review)

1. **BUG-031 layering** — importing `export_stateful_onnx.py` (a script) from `fvml` would
   be an inverted dependency; moving `noncommercial_license` into `fvml/export.py` and
   re-importing in the script is the fix. *Adjustment applied to plan.*
2. **BUG-031 `audio_rows` filter** — the `{k: v ... if v is not None}` pass-through means
   a naive `row["noncommercial"] = r.get("noncommercial")` would drop `False` silently and
   look inconsistent; set the key only when truthy. *Applied.*
3. **BUG-029 test determinism** — "spread readiness with ×40 weights and hope" is not a
   regression test; logits must be scripted so a 2-write at constant `k` is guaranteed.
   Crafting the head + one latent dim makes it deterministic. *Applied.*
4. **BUG-029 threshold interaction** — with `2·sigmoid`, `readiness_threshold = 0.5` now
   rejects logits < −1.385 instead of < 0. That is the intended `[0,2]` semantics (blank
   chunks bank nothing), noted in the stage doc. No policy change.
5. **BUG-030 rig redesign risk** — making the fixture decoder terminate changes the AL
   numbers the e2e test asserts; bounds must be re-derived, and the never-EOS decoder must
   remain under test as the negative case (it is the regression the report demands).
   *Both models kept in the rig.*
6. **BUG-030 kind mismatch** — the existing rig writes `kind: "speech_silence"`, the real
   list uses `trailing_silence`; the eval fix must not special-case the rig's typo'd kind.
   *Rig aligned to the real schema.*
7. **BUG-030 TSV regeneration** — the generator needs `musan.jsonl` (absent here), so the
   committed TSV is hand-edited to match the generator change; flagged for `--check`
   re-verification on a data-complete machine. Risk: if the hand edit diverges, `--check`
   catches it there. *Accepted residual risk, documented.*
8. **BUG-030 tail-word cost** — a second Whisper pass over 10 tail slices is negligible,
   but it must happen inside the existing Whisper session (the ASR object is closed right
   after the first pass). *Restructure noted.*
9. **BUG-032 union-vs-override** — the report suggested override; union is chosen because
   override makes Mode-B bundles unfilterable by non-voice languages and would break the
   existing `f.language="de"` expectation for `langs.json` bundles. Reviewer decision
   point; documented in the code comment.
10. **Twin discipline** — adding `flushes_without_eos` touches both policy twins; it is an
    observer (no decision change), so goldens stay valid, but `make_waitk_golden.py --check`
    and the waitk test suites must be rerun to prove it.
